Designed to run seamlessly across desktop environments and Android via Kivy. ## Features - **Multi-Agent Architecture**: Specialized agents for research, coding, planning, and testing. - **Asynchronous Service Layer**: Non-blocking asynchronous bridge connecting the Kivy Android frontend to the Python orchestration engine. - **Cross-Provider AI Integration**: Native support for Google Gemini, Groq, and Anthropic Claude APIs. - **Persistent Storage**: Local SQLite memory and knowledge management. - **Android Support**: Fully configured for Kivy and Buildozer ARM64 compilation.
